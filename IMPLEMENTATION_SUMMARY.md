## 🚀 How to Use

### For Users
1. Visit https://3dprint-omsk.ru
2. Scroll down to "Заказать 3D печать" section
3. Fill all required fields
4. Optionally upload 3D model file
5. Click "Отправить заказ"
6. Wait for confirmation message

### For Developers
1. Form auto-initializes via DOMContentLoaded
2. Validation happens on submit
3. FormData sent to /order-submit.php
4. Response handled by OrderFormHandler
5. Success/error displayed to user

### For Testing
1. Open /test-order-form.html
2. Follow testing checklist
3. Check console (F12) for logs
4. Check Network tab for API calls
5. Verify Telegram notification received

## 📝 Form Field Specifications

| Field | Name | Type | Required | Validation |
|-------|------|------|----------|------------|
| ФИО | fio | text | Yes | 2-100 chars |
| Email | email | email | Yes | Valid email |
| Телефон | phone | tel | Yes | Min 10 chars |
| Telegram | telegram | text | Yes | 3-32 chars, alphanumeric+_, no @ |
| Услуга | service | select | Yes | One of 5 options |
| Описание | description | textarea | Yes | 10-2000 chars |
| Файл | files | file | No | .stl,.obj,.gcode,.step,.3mf,.amf,.ply, max 50MB |
