FORM SUBMISSION FLOW ✅
================================================================================

1. User submits form
   ↓
2. preventDefault() stops default submit
   ↓
3. Frontend validation runs
   ↓
4. Honeypot check (silent success for bots)
   ↓
5. Show loading state (spinner on button)
   ↓
6. Prepare data:
   - Map: fio → name
   - Append telegram to description
   ↓
7. Check for file upload:
   - YES → Use FormData (multipart/form-data)
   - NO  → Use JSON (application/json)
   ↓
8. POST to /order-submit.php
   ↓
9. Handle response:
   - Success (200 + success: true):
     * Show green success message
     * Reset form
     * Clear file info
     * Scroll to message
   - Error:
     * Show red error message
     * Keep form data
     * Display field-specific errors
   ↓
10. Clear loading state
