## 📊 Available Bot Commands

Users can send these commands to the bot:

| Command | Description | Response |
|---------|-------------|----------|
| `/start` | Begin interaction with bot | Prompts for password if not authenticated |
| `/stop` | Unsubscribe from notifications | Removes user from authorized list |
| `/help` | Show available commands | Lists all commands and current status |
| `/status` | Check subscription status | Shows user info and subscription details |

## 🔒 Security Features

### Implemented Security:
✅ **Webhook Secret Token** - Validates requests are from Telegram
✅ **Password Authentication** - Only authorized users receive notifications
✅ **Rate Limiting** - Max 5 orders per IP per hour
✅ **Honeypot Protection** - Catches bot submissions silently
✅ **Input Validation** - Server-side validation of all fields
✅ **File Upload Security** - Whitelist of allowed extensions, size limits
✅ **Secure Storage** - User data and logs in protected directories
✅ **Environment Variables** - Sensitive data in .env (not in git)

### .env File Security:
```bash
# Secure the .env file
chmod 600 .env
chown www-data:www-data .env  # Or your web server user
```

### Storage Directory Security:
```bash
# Restrict access to storage
chmod 755 storage/
chmod 755 storage/data/
chmod 755 storage/logs/
chmod 755 storage/uploads/
chmod 755 storage/cache/

# Create .htaccess to prevent direct access (Apache)
echo "Deny from all" > storage/.htaccess

# Or for Nginx, add to server config:
# location ~ ^/storage/ {
#     deny all;
#     return 404;
# }
```

## 🐛 Troubleshooting

**Check logs:**
```bash
tail -n 50 storage/logs/telegram.log
```

**Verify bot token:**
```bash
# Check .env file has correct token
cat .env | grep TELEGRAM_BOT_TOKEN
```

**Test API connection:**
```bash
curl https://api.telegram.org/bot8241807858:AAE0JXxWO9HumqesNK6x_vvaMrxvRK9qKBI/getMe

```

**Verify password in .env:**
```bash
cat .env | grep TELEGRAM_PASSWORD
# Should show: TELEGRAM_PASSWORD=852789456
```

**Check webhook logs:**
```bash
tail -f storage/logs/telegram.log
# Look for: "Failed authentication attempt"
```

### Problem: Orders not sending to Telegram

**Check order logs:**
```bash
tail -f storage/logs/orders.log
```

**Verify TelegramBot is loaded:**

**Check upload directory:**
```bash
ls -la storage/uploads/orders/
```

**Check PHP upload settings:**

**Verify permissions:**

## 📚 Integration Examples

### Send Custom Notification

```php
<?php
require_once __DIR__ . '/php/TelegramBot.php';

$bot = new TelegramBot();

$message = "🎉 <b>Важное уведомление!</b>\n\n";
$message .= "Это кастомное сообщение для всех подписчиков.";

$results = $bot->broadcastMessage($message);

echo "Sent to " . count($results) . " users\n";
```

### Check if User is Authorized

```php
<?php
require_once __DIR__ . '/php/TelegramBot.php';

$bot = new TelegramBot();
$chatId = 123456789;

if ($bot->isAuthorized($chatId)) {
    echo "User is authorized\n";
} else {
    echo "User is not authorized\n";
}
```

### Send to Specific User

```php
<?php
require_once __DIR__ . '/php/TelegramBot.php';

$bot = new TelegramBot();
$chatId = 123456789;

$message = "👋 Привет! Это личное сообщение.";
$response = $bot->sendMessage($chatId, $message);

if ($response['ok']) {
    echo "Message sent successfully\n";
} else {
    echo "Failed to send message\n";
}
```
