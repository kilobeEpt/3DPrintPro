========================================
RELATIONSHIPS SUMMARY
========================================

forms
  ├── hasMany: form_fields
  └── hasMany: form_submissions

form_fields
  ├── belongsTo: forms
  └── hasMany: form_submission_values

form_submissions
  ├── belongsTo: forms
  ├── hasMany: form_submission_values
  └── hasOne: orders (inverse)

form_submission_values
  ├── belongsTo: form_submissions
  └── belongsTo: form_fields (nullable)

orders
  └── belongsTo: form_submissions (optional)

settings_audit
  (Independent - logs only)

========================================
QUERY PATTERNS
========================================

1. Get form with fields:
   SELECT * FROM forms f
   LEFT JOIN form_fields ff ON f.id = ff.form_id
   WHERE f.slug = 'contact'
   ORDER BY ff.sort_order;

2. Get submission with values:
   SELECT * FROM form_submissions fs
   LEFT JOIN form_submission_values fsv 
     ON fs.id = fsv.form_submission_id
   WHERE fs.id = 123;

3. Get order with form data:
   SELECT 
     o.*,
     fs.submitted_data,
     f.name as form_name
   FROM orders o
   LEFT JOIN form_submissions fs 
     ON o.form_submission_id = fs.id
   LEFT JOIN forms f 
     ON fs.form_id = f.id
   WHERE o.id = 456;

4. Search by field value:
   SELECT DISTINCT fs.*
   FROM form_submissions fs
   JOIN form_submission_values fsv 
     ON fs.id = fsv.form_submission_id
   WHERE fsv.field_name = 'phone'
     AND fsv.field_value LIKE '%+7%';

5. Get audit trail:
   SELECT * FROM settings_audit
   WHERE setting_key = 'telegram_chat_id'
   ORDER BY created_at DESC;
