# Telegram Bot - Password Authentication System

## Overview

This Telegram bot system provides password-based authentication for receiving order notifications. Users must authenticate with a password before they can receive notifications.

## Features

- ✅ Password-based authentication
- ✅ Multi-user support (broadcast to all authorized users)
- ✅ Command handlers (/start, /stop, /help, /status)
- ✅ Webhook integration with secret validation
- ✅ Comprehensive logging
- ✅ Error handling with retry logic
- ✅ User management commands

## Setup Instructions

### 1. Configure Environment

Copy `.env.example` to `.env` and ensure these variables are set:

```bash
cp .env.example .env
```

Edit `.env` and verify:
- `TELEGRAM_BOT_TOKEN` - Your bot token from BotFather
- `TELEGRAM_PASSWORD` - Password for authentication (default: 852789456)
- `APP_URL` - Your site URL (e.g., https://3dprint-omsk.ru)

### 2. Set Up Webhook

Run the setup script to configure the webhook:

```bash
php telegram/setup-webhook.php
```

This will:
- Generate a webhook secret token
- Save it to `.env`
- Register the webhook with Telegram
- Verify the webhook is working

### 3. Test Authentication

1. Open Telegram and find your bot
2. Send `/start` command
3. Bot will ask for password
4. Enter: `852789456`
5. Bot will confirm subscription

### 4. Test Notifications

Send a test notification to all authorized users:

```bash
php telegram/test-notification.php
```

## Bot Commands

Users can interact with the bot using these commands:

- `/start` - Start using the bot and authenticate
- `/stop` - Unsubscribe from notifications
- `/help` - Show help message
- `/status` - Check subscription status

```bash

```

Shows all authorized users with their details.

### Show User Info

```bash
php telegram/manage-users.php info <chat_id>
```

Display detailed information about a specific user.

### Remove User

```bash
php telegram/manage-users.php remove <chat_id>
```

Remove a user from the authorized list. The user will be notified.

## Usage in Code

### Send Order Notification

```php
<?php
require_once __DIR__ . '/php/TelegramBot.php';

$bot = new TelegramBot();

$order = [
    'orderNumber' => 'ORD-12345',
    'clientName' => 'Иван Иванов',
    'clientPhone' => '+7 (913) 123-45-67',
    'clientEmail' => 'ivan@example.com',
    'service' => '3D печать FDM',
    'amount' => 2500,
    'details' => 'Печать детали из PLA'
];

// Send to all authorized users
$results = $bot->sendOrderNotification($order);
```

### Send Custom Message

```php
// Broadcast to all authorized users
$bot->broadcastMessage("🎉 <b>Special announcement!</b>\n\nCheck out our new services!");

// Send to specific user
$bot->sendMessage($chatId, "Hello! Your order is ready.");
```

### Check User Authorization

```php
if ($bot->isAuthorized($chatId)) {
    echo "User is authorized";
}
```

### Get Authorized Users

```php
$chatIds = $bot->getAuthorizedUsers();
echo "Total authorized users: " . count($chatIds);
```

## Troubleshooting

### Webhook Not Working

Check webhook status:

```bash
php telegram/setup-webhook.php
```

Look for errors in the webhook info.

### No Notifications Received

1. Check if users are authorized:
   ```bash
   php telegram/manage-users.php list
   ```

2. Test notifications:
   ```bash
   php telegram/test-notification.php
   ```

3. Check logs:
   ```bash
   tail -f storage/logs/telegram.log
   ```

1. Verify password in `.env`:
   ```bash
   grep TELEGRAM_PASSWORD .env
   ```

2. Check logs for failed attempts:
   ```bash
   grep "Failed authentication" storage/logs/telegram.log
   ```

### Bot Not Responding

1. Verify bot token:
   ```bash
   grep TELEGRAM_BOT_TOKEN .env
   ```

2. Check webhook is set correctly:
   ```bash
   php telegram/setup-webhook.php
   ```

3. Ensure webhook URL is accessible from internet

## API Reference

### TelegramBot Class Methods

#### `authenticate($chatId, $password, $userInfo)`
Authenticate user with password and save to authorized list.

**Parameters:**
- `$chatId` (int) - Telegram chat ID
- `$password` (string) - Password to verify
- `$userInfo` (array) - User information from Telegram

**Returns:** `bool` - True if authenticated

#### `getAuthorizedUsers()`
Get array of authorized chat IDs.

**Returns:** `array` - Array of chat IDs

#### `isAuthorized($chatId)`
Check if user is authorized.

**Parameters:**
- `$chatId` (int) - Telegram chat ID

**Returns:** `bool` - True if authorized

#### `sendMessage($chatId, $message, $options)`
Send message to specific user.

**Parameters:**
- `$chatId` (int) - Telegram chat ID
- `$message` (string) - Message text (HTML formatted)
- `$options` (array) - Additional options

**Returns:** `array` - Telegram API response

#### `broadcastMessage($message, $options)`
Send message to all authorized users.

**Parameters:**
- `$message` (string) - Message text (HTML formatted)
- `$options` (array) - Additional options

**Returns:** `array` - Array of responses per chat_id

#### `removeUser($chatId)`
Remove user from authorized list.

**Parameters:**
- `$chatId` (int) - Telegram chat ID

**Returns:** `bool` - True if removed

#### `sendOrderNotification($order)`
Send formatted order notification to all authorized users.

**Parameters:**
- `$order` (array) - Order data

**Returns:** `array` - Broadcast results
