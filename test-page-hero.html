QA Testing Checklist

  • Visual Design: No white background stands out, clean theme-aware colors
  • Light Theme: Page hero uses var(--bg) background, subtle border at bottom
  • Dark Theme: Page hero background matches dark theme, enhanced contrast
  • Breadcrumbs: Proper spacing (--space-8 gap), no harsh background
  • Breadcrumbs Links: Text-secondary color, hover shows primary, underline on hover
  • Breadcrumbs Focus: Visible focus ring with outline and box-shadow
  • Typography H1: Responsive clamp(1.5rem → 2rem), proper line-height 1.2
  • Typography P: Responsive clamp(1rem → 1.125rem), secondary color, line-height 1.6
  • Spacing: Design tokens used (--space-64 vertical, --space-40 horizontal on desktop)
  • Desktop (≥1024px): Padding --space-64 / --space-40, h1 2rem, p 1.125rem
  • Tablet (768-1024px): Padding --space-48 / --space-32, reduced font sizes
  • Mobile (≤768px): Padding --space-32 / --space-24, smaller fonts, reduced breadcrumb gap
  • Breadcrumb Mobile: Font-size 0.8125rem, gap --space-4, margin-bottom --space-16
  • Text Wrapping: Long breadcrumbs wrap properly without overflow
  • Keyboard Navigation: Tab through breadcrumbs, focus states visible
  • Theme Toggle: Seamless transition between light and dark themes
  • Consistency: All three pages (services, portfolio, contact) look identical in structure
  • No Gradient: No gradient background, simple clean design
  • Border: 1px solid border at bottom using --card-border
  • Dark Theme Border: Border uses rgba(255,255,255,0.1) for proper contrast
